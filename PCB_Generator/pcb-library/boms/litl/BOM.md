## Notes

- This is a 40% keyboard with up to 45 keys
- Uses Pro Micro footprint (Elite-C or Nice!nano compatible)
- Only through-hole components (except controller)
- Supports 1-2 rotary encoders
- Optional OLED display
- Multiple layout options (split space, split shift, stepped capslock)
- Open component aesthetic

## Layout Options

- Split spacebar
- Split right shift
- Stepped capslock
- 1-2 rotary encoders
