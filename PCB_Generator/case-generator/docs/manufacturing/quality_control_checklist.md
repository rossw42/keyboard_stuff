## FUNCTIONAL FIT TESTING

### 10. PCB Fit Test (Top Frame)

| Test | Criteria | Pass/Fail | Notes |
|------|----------|-----------|-------|
| PCB Drops Into Cavity | PCB fits without forcing | ☐ Pass ☐ Fail | ____________ |
| PCB Sits Flat | No rocking or gaps >0.5mm | ☐ Pass ☐ Fail | ____________ |
| Clearance Around PCB | 0.5-1mm gap on all sides | ☐ Pass ☐ Fail | ____________ |
| Standoff Alignment | Standoffs align with PCB holes | ☐ Pass ☐ Fail | ____________ |
| M2 Screw Test | M2 screws engage standoffs smoothly | ☐ Pass ☐ Fail | ____________ |

**Test Procedure:**
1. Place PCB into top frame cavity
2. Verify PCB sits flat on standoffs (use feeler gauge if needed)
3. Check clearance around PCB perimeter
4. Thread M2 screws through PCB holes into standoffs (hand tight only)
5. All 6 screws should engage smoothly

**Pass Criteria**: PCB fits properly, all screws engage  
**Fail Action**: 
- Cavity too tight: Can be enlarged with sanding
- Standoffs misaligned: Check brass insert installation
- Screws don't engage: Check insert threads

### 11. Case Assembly Test

| Test | Criteria | Pass/Fail | Notes |
|------|----------|-----------|-------|
| Parts Mate Properly | Top and bottom align without forcing | ☐ Pass ☐ Fail | ____________ |
| Hole Alignment | All 6 mounting holes align | ☐ Pass ☐ Fail | ____________ |
| M3 Screw Engagement | All screws thread smoothly | ☐ Pass ☐ Fail | ____________ |
| Screw Heads Flush | Flat heads sit flush with bottom | ☐ Pass ☐ Fail | ____________ |
| No Gaps When Assembled | Mating surfaces touch uniformly | ☐ Pass ☐ Fail | ____________ |
| Case Feels Solid | No flexing or creaking | ☐ Pass ☐ Fail | ____________ |

**Test Procedure:**
1. Place top frame on bottom tray
2. Verify parts align naturally
3. Insert all 6 M3 × 12mm screws from bottom
4. Tighten screws in star pattern (opposite corners) to 0.8-1.0 Nm
5. Check for gaps between parts
6. Apply gentle pressure to test rigidity

**Pass Criteria**: Parts assemble smoothly, no gaps, feels solid  
**Fail Action**:
- Holes misaligned: Check hole locations, may need to enlarge slightly
- Gaps present: Check for debris, verify surfaces are flat
- Flexing: Check screw tightness and floor thickness

## Pass/Fail Criteria Summary

### PASS Criteria
- All dimensional measurements within specified tolerances
- All functional fit tests successful
- No major visual defects
- All hardware installs correctly
- Case assembles properly with no gaps or misalignment

### FAIL Criteria (Automatic Rejection)
- Floor thickness <1.8mm (structural concern)
- Cavity depth out of tolerance (PCB won't fit)
- Mounting holes misaligned >1mm (assembly impossible)
- Brass inserts damaged or crooked (threads don't work)
- Major cracks or structural defects
- Large areas of tear-out that cannot be sanded

### Rework Criteria (May Be Salvageable)
- Minor dimensional deviations that don't affect function
- Surface finish issues that can be sanded
- Minor tear-out <2mm that can be filled and sanded
- Holes slightly misaligned but can be enlarged
- Countersinks too shallow (can be re-cut)

---

## Notes and Best Practices

1. **Measure Twice**: Always verify critical dimensions at multiple points
2. **Document Everything**: Note all measurements and observations
3. **Test Functionally**: Don't rely on dimensions alone - test actual fit
4. **Inspect Early**: Catch issues during machining, not after finishing
5. **Be Consistent**: Use same measurement techniques for all parts
6. **Calibrate Tools**: Verify calipers and gauges are accurate
7. **Good Lighting**: Proper lighting reveals defects that might be missed
8. **Take Photos**: Document any defects or issues for records
