# Keyboard Stuff Workspace Context

This workspace contains a collection of keyboard design tooling, documentation, and Ergogen/QMK-related projects.

Use the repository contents as the primary source of truth when answering questions or making changes.

Key areas:
- `README.md` — top-level overview for this workspace
- `ergogen/` — Ergogen/Python-based keyboard and PCB generation work
- `keyboards/` — keyboard layout files and data
- `KLE_SCAD_Ergogen/` — KLE-to-Ergogen conversion tooling
- `PCB_Generator/` — PCB generation and helper utilities
- `qmk_utilities/` — QMK-related scripts and helpers
- `scripts/` — miscellaneous automation scripts
- `switch_research/` — switch research database and associated docs
- `woodkeyboard-case/` — case design files and assets

When working in this workspace, prefer actual files and repository structure over external assumptions. If a request involves keyboard firmware or PCB generation, first check the relevant project directories and documentation before suggesting changes.

## Recommended behavior
- Inspect `README.md` and subproject README files first
- Use workspace markdown docs as context
- Avoid inventing APIs or features that aren’t present in repository files
- Reference existing tooling and examples in this workspace where possible
