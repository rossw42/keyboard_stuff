# Boston - VIAL keymap

VIAL-enabled keymap for the Boston keyboard.

## Details

- Processor family: ARM
- Lighting: qmk_backlight_rgblight
- Encoders: 1
- Split: no

## Build

```bash
make boston:vial
```

## Flash

```bash
make boston:vial:flash
```

Then open the board in [Vial](https://get.vial.today/).
