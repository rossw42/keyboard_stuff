## Correct Format Summary

### What We've Verified Against Real Files:

✓ **All key positions use `[{"x": N}, "r,c"]` wrapping** (not just wide keys)  
✓ **Multi-row layouts correctly preserve row/column positions**  
✓ **Wide keys use float x values (`x=0.5`, `x=1.75`, etc.)**  
✓ **Multi-key rows preserved as array with multiple entries**  
✓ **Color and switch metadata preserved in appropriate format**


### Common VIAL Format Patterns Found:

#### Pattern 1: Standard Key Position
```json
[{"x": 0, "y": 0}, "0,0"]
// x/y coordinates for standard key alignment
```

#### Pattern 2: Wide/Centred Key  
```json
[{"x": 0.5}, "0,4"]
// Float value indicates wide or centered position
```

#### Pattern 3: Multi-Key Row Entry
```json
[
  {"x": 8.5},            // First key in array
  "0,11",                // Coordinate string  
  {"c": "#777777"}       // Optional color metadata
]
```

#### Pattern 4: Wide Key with Offset
```json
[{"x": 3.25, "y": 1, "w": 1.5}, "1,2"]
// Float x position, wide key flag, row/col coordinates
```
