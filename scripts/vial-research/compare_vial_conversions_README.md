# Compare Vial Conversions

Batch comparison tool for comparing generated `vial.json` files against real reference files to identify conversion differences.

## Overview

This script compares `vial.json` files that were generated by the converter against their original "real" reference files, identifying any differences between generated and actual data.

## Usage

```bash
python compare_vial_conversions.py [keyboard_keyboards_dir] [--csv-reference PATH]
```

### Arguments

- `[keyboards_dir]` (optional): Directory containing `keyboard.json` files. Defaults to `D:/GitHub2/vial-qmk/keyboards`

**Example:**
```bash
python compare_vial_conversions.py "D:/GitHub2/vial-qmk/keyboards"
```

## Output Format

The tool outputs results in two formats:

1. **Console Output**: Console output showing comparison results for each keyboard
- Shows which keyboards have perfect matches
- Shows differences with details about differences found
- Shows count of keymap entries compared

2. **JSON Results File**: Results are saved to `comparison_results.json` in the current directory, containing:
   - List of all keyboards processed
- Comparison results for each keyboard (status, differences, entry counts)

## Comparison Algorithm

The comparison process:

1. **Load Files**: Load generated and real vial.json files
4. Compare top-level fields (name, vendorId, productId, lighting)
5. Compare matrix structure (rows, cols)
6. Compare keymap entries (first 5 entries for structure check)
- Report differences found

## Comparison Algorithm

The comparison process:

1. Load generated and real vial.json files
2. Compare top-level fields (name, vendorId, productId, lighting)
3. Compare matrix object (rows, cols)
4. Compare keymap structure and entries
5. Return comparison results with differences found
