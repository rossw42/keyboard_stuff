## Build pipeline

### PCB, plates, cases and case STLs via Ergogen
Review/edit `biaxial.ergogen.yaml`, then run Ergogen on it
(also renders the case STLs):
```
python -m kbforge biaxial.ergogen.yaml -o <out>
```
* `ergogen/outlines/plate.dxf` — laser-cut/CNC switch plate
* `ergogen/outlines/pcb_outline.dxf` — board edge
* `ergogen/pcbs/*.kicad_pcb` — open in KiCad, route, fabricate
* `ergogen/cases/*.jscad` — case_bottom / case_walls / case_plate 3D models
* `ergogen/cases/*.stl` — the same case models, rendered printable

Or manually:
```
npx ergogen biaxial.ergogen.yaml -o output/
npx --yes @jscad/cli@1 output/cases/case_bottom.jscad -o output/cases/case_bottom.stl
```

### 3D-printed plate & case via OpenSCAD (standalone)
```
openscad -o plate.stl  -D 'part="plate"'  biaxial.scad
openscad -o bottom.stl -D 'part="bottom"' biaxial.scad
```

### Printable hotswap PCB via hotswap_pcb_generator
Copy `biaxial.hotswap.scad` into the hotswap_pcb_generator `scad/` folder
and set it as the layout include; render its pcb/plate/case parts.
