# Lily58 Optimized Layout Changes

## Overview
Optimized for **coding and documentation writing** workflows on macOS.

---

## Layer 0 (Base) - UNCHANGED ✓
Your base layer is solid! Keeping all your tap dances and layout as-is.

---

## Layer 1 (Symbol Layer) - UNCHANGED ✓
Access: Hold Space (LT1)
- F-keys and symbols work well for coding
- No changes needed

---

## Layer 2 (Nav/Function Layer) - IMPROVED 🚀
Access: Hold Enter (LT2)

### LEFT SIDE - Media & Productivity
**Top Row:** Media controls
- Previous Track, Play/Pause, Next Track, Stop, Mute

**Row 2:** Brightness
- Brightness Down, Brightness Up

**Row 3:** Navigation Cluster
- Home, Page Up, Page Down, End

**Row 4:** Mac Shortcuts (for coding)
- Cmd+Z (Undo), Cmd+X (Cut), Cmd+C (Copy), Cmd+V (Paste)

### RIGHT SIDE - Navigation
- Delete key (top right)
- Arrow keys in inverted-T layout
- Symbols: \ ] [ = - +

**Why:** Removed redundant number row and F-keys. Added essential media controls and navigation shortcuts you'll use constantly while coding.

---

## Layer 3 (NEW!) - Window Management + Numpad 🎯
Access: Hold both Space + Enter simultaneously

### LEFT SIDE - Window Management
**Row 1:** Desktop switching (Cmd+Ctrl+Alt+1-4)

**Row 2:** Window snapping
- Snap Left, Maximize, Snap Right, Fullscreen
- (Compatible with Rectangle, Magnet, or macOS native)

**Row 3-4:** Quick app switching
- Cmd+1 through Cmd+0 (switch to apps in dock)

### RIGHT SIDE - Numpad
Full numpad layout on right hand:
```
  *  7  8  9  -
  /  4  5  6  +
  .  1  2  3  =
     0  0  .  ↵
```

**Why:** Numpad for data entry, calculations, and spreadsheets. Window management for efficient multitasking while coding.

---

## Encoder Improvements 🎛️

### Layer 0 (Base)
- **Left:** Volume Up/Down ✓ (unchanged)
- **Right:** None

### Layer 1 (Symbol)
- **Left:** Horizontal Scroll (great for wide code files)
- **Right:** None

### Layer 2 (Nav)
- **Left:** Tab Switching (Cmd+Shift+[ and ])
  - Perfect for switching between code files
- **Right:** None

### Layer 3 (Window/Numpad)
- **Left:** Workspace Switching (Ctrl+Left/Right)
  - Switch between virtual desktops
- **Right:** None

---

## Tap Dance Improvements ⚡

### TD(4) - A key
- **Before:** 200ms delay
- **After:** 175ms delay
- Faster response for Select All (Cmd+A)

### TD(7) - NEW! S key
- **Single tap:** S
- **Double tap:** Cmd+S (Save)
- Quick save while typing!
