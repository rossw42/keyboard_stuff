# Cities Skylines 2 - Corne Left Side Keymap

## Overview
This keymap transforms the left side of a Corne keyboard into a dedicated Cities Skylines 2 macropad with 4 layers for different game functions.

## Layer Descriptions

### Layer 0 - CAMERA & MOVEMENT (Default Layer)
**Most frequently used controls for camera movement and basic game functions**
- **Top Row**: Camera rotation up (T), forward movement (W), zoom in (R), focus selection (U), info view (I), progression (P)
- **Middle Row**: Camera rotation left (Q), move left (A), move back (S), move right (D), camera rotation right (E), zoom out (F)
- **Bottom Row**: Camera rotation down (G), city economy (Z), transportation overview (X), city information (C), city statistics (V), bulldozer (B)
- **Thumbs**: Layer 1 access, pause simulation (Space), back/cancel (Esc)

### Layer 1 - SPEED & TOOLS
**Game speed controls and essential building tools**
- **Top Row**: Hide UI (`), normal speed (1), fast speed (2), super fast speed (3), quick save (F5), quick load (F9)
- **Middle Row**: Map tiles (M), increase elevation (Page Up), decrease elevation (Page Down), photo mode (.), take photo (Enter)
- **Thumbs**: Layer 2 access from middle thumb

### Layer 2 - EDITOR TOOLS
**Advanced editor functions for precise building**
- **Top Row**: Clone (C), auto connect (O), auto align (P), move selected (M)
- **Middle Row**: Align X axis (X), align Y axis (Y), align Z axis (Z)
- **Thumbs**: Layer 3 access from right thumb

### Layer 3 - MACROS & CUSTOM
**Programmable macros for complex actions**
- All 18 keys available for custom macros
- Examples: Building sequences, camera presets, tool combinations

## Key Features

1. **Ergonomic Design**: Most frequently used camera controls on home row
2. **Logical Grouping**: Related functions grouped by layer
3. **Progressive Complexity**: Basic → Speed/Tools → Editor → Macros
4. **Thumb Layer Access**: Easy layer switching with thumb keys
5. **Macro Expansion**: Full layer dedicated to custom macros

## Implementation Notes

- Use QMK or VIAL firmware for the Corne keyboard
- Configure as left-side only macropad
- Set up layer switching with momentary holds on thumb keys
- Program macros in Layer 3 for complex building sequences
- Consider RGB underglow to indicate active layer

## Recommended Macro Examples for Layer 3

1. **Quick Road Network**: Place road → Connect to existing → Auto-align
2. **Zoning Combo**: Select residential → Place multiple zones → Connect utilities
3. **Camera Presets**: Save/recall specific camera positions
4. **Building Sequences**: Common building placement patterns
5. **Emergency Tools**: Quick access to disaster response tools
6. **Economic Shortcuts**: Tax adjustment → Budget review → Statistics check
